**Aria MD** 0.1.0 : Éditeur et lecteur Markdown simple : code et aperçu, plan cliquable, raccourcis de mise en forme, 100 % local

## Nouveautés

C'est la première version.

- **Éditeur** : ouvre, modifie et enregistre un fichier Markdown (UTF-8, fins de ligne conservées). Avant de remplacer un fichier, l'ancien contenu est copié, daté, dans `%USERPROFILE%\.Aria-MD\sauvegardes` (les dix dernières copies sont gardées). Fermer avec des modifications non enregistrées demande quoi en faire.
- **Trois vues** : Code, Aperçu, ou les deux côte à côte (Double), avec un défilement lié. L'aperçu se met à jour pendant la frappe ; il ne charge ni image ni adresse et n'affiche pas de HTML.
- **Raccourcis de mise en forme** dans la barre latérale : titres H1 à H6, gras, italique, barré, surligné, souligné, code, listes à puces, numérotées et de tâches, citation, bloc de code, lien, image, tableau, séparateur, avec leurs raccourcis clavier (Ctrl+B, Ctrl+I, Ctrl+1 à 6…).
- **Blocs de code** : une liste de langages à cliquer pose le bloc dans le langage choisi (ou change celui d'un bloc existant) ; l'aperçu écrit le langage en étiquette, colore le code (JavaScript, Python, Rust, PowerShell, HTML, CSS, JSON, YAML, SQL… 32 langages) et propose un bouton Copier. Sans langage écrit, il reconnaît le code quand il est assez sûr et le dit (« détecté ») ; un clic sur un code en ligne le copie.
- **Plan** : les titres du document, cliquables (le curseur, le code et l'aperçu vont sur le titre), avec une recherche, un repli par niveau et une numérotation.
- **Brouillon** : le texte non enregistré est gardé en brouillon ; si l'appli s'arrête avant l'enregistrement, elle propose de le récupérer au lancement suivant.
- **Fond animé** « Markdown qui se rend » : des lignes de Markdown fantômes s'écrivent, se rendent, puis s'effacent. Il se règle (ou se coupe) dans Paramètres, et s'arrête si Windows demande moins d'animations.
- Journal des opérations, recherche de mises à jour sur GitHub (désactivable), installation dans `%USERPROFILE%\.Aria-MD\programme` proposée au premier lancement.

## À savoir

- Aria MD fonctionne entièrement en local. Le seul accès réseau est la recherche d'une version plus récente sur GitHub, que tu peux couper dans Paramètres ; l'appli n'installe jamais rien sans ton accord.
- L'éditeur n'ouvre que des fichiers en UTF-8 de moins de 10 Mo : un autre encodage est refusé plutôt que converti en silence.

## Installation

1. Télécharge `Aria-MD-0.1.0.zip` ci-dessous.
2. Décompresse d'abord le zip en entier (clic droit, « Extraire tout »).
   Lancé depuis l'aperçu du zip dans l'Explorateur, l'exe démarre sans les fichiers livrés à côté de lui.
3. Lance `Aria-MD.exe`.
   Choisis « Installer » pour le ranger dans `%USERPROFILE%\.Aria-MD\programme`, ou « Lancer sans installer ».
4. L'exe n'est pas signé : si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations
   complémentaires », puis sur « Exécuter quand même ».

## Mise à jour depuis une version précédente

L'appli te propose elle-même la nouvelle version : elle remplace l'exe là où il est et garde la précédente.

Pour le faire à la main : ferme l'appli, décompresse le nouveau zip en entier, puis
lance son exe et choisis « Installer » : la version installée est remplacée, la précédente est gardée.

Tes réglages sont dans `%USERPROFILE%\.Aria-MD` et sont repris tels quels.

## Comment vérifier ce que tu as téléchargé

L'empreinte du zip est dans `Aria-MD-0.1.0.zip.sha256`. Dans PowerShell :

```powershell
(Get-FileHash .\Aria-MD-0.1.0.zip -Algorithm SHA256).Hash
```

L'empreinte seule ne prouve pas d'où vient le fichier. Pour vérifier qu'il a bien été construit par ce dépôt :

```powershell
gh attestation verify .\Aria-MD-0.1.0.zip --repo ZedjeK/Aria-MD
```
